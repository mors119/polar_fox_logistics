# 기여 가이드

## 원칙

- 공통 입력 판별 뒤의 상품/주문 검증 및 적재 흐름은 분리합니다.
- 폴더명, 시트명, 헤더명은 설정 파일에서 먼저 확인합니다.
- 실제 운영 동작이 바뀌면 README와 운영 문서를 같이 수정합니다.

## 변경 전 확인

- 이 변경이 상품 CSV인지 주문 CSV인지
- 입력 유형 판별에 필요한 필수 헤더가 무엇인지
- 적재 대상 시트가 어디인지
- 실패 시 어떤 이력/오류 로그가 남아야 하는지

## PR 전 확인

- `npm run format`
- `npm test`
- `npm run lint`
- 수동으로 초기화 함수와 스캔 함수 동작 확인
